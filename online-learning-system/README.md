# 🎓 Online Learning System - SBA301

Dự án Hệ thống Quản lý và Học Trực Tuyến xây dựng trên nền tảng **Spring Boot 3 (Java 17)** kết hợp template engine **Thymeleaf** và **MySQL**.

---

## 📌 Tài Liệu Hướng Dẫn & Tài Khoản Mẫu

👉 Chi tiết tài khoản đăng nhập (Admin, Customer, Expert, Sale, Marketing), cách đổi tên Database, sửa mật khẩu kết nối MySQL và cách chạy lại Seed dữ liệu mẫu được ghi chi tiết tại:
